# Carnet B Academy — GitHub Pages deployment

1. Create a new GitHub repository named `carnet-b-academy` (Public is simplest).
2. On the repository page, choose **Add file → Upload files**.
3. Upload the **contents** of this extracted package to the repository's root, not the ZIP file and not a containing folder.
4. Commit changes on the `main` branch.
5. Select **Settings → Pages → Build and deployment**, Source **Deploy from a branch**, Branch **main**, Folder **/(root)**, then Save.
6. After the deployment succeeds, use the **Visit site** link in Settings → Pages.

URL: https://YOUR-GITHUB-USERNAME.github.io/carnet-b-academy/

This is a static website. User progress remains in local browser storage; different browsers or devices do not automatically share progress. Published sites are publicly accessible.
